# Security Policy

Onlib in this repository is a static hackathon prototype, not a secure production service.

- Do not enter real personal information or payment-card details.
- Do not reuse a real password.
- Do not treat demo memberships as paid subscriptions.
- Demo accounts and app data are stored in browser `localStorage`.

A production version must implement server-side authentication and authorization, strong password hashing, secure sessions, rate limiting, email verification and password reset, secrets management, HTTPS, audit logging, verified payment webhooks, duplicate-payment protection, backups and security testing.

Report prototype concerns privately to the repository maintainer rather than publishing sensitive details in an issue.
