# Onlib
### Your next favourite book is waiting.

Onlib is an online library website concept built for the Odoo Online Hackathon. The idea is simple: make discovering books and managing a library membership easy, convenient, and enjoyable.

The website has a clean layout, a friendly design, and features for readers to explore books and choose a membership plan.

## What can you do with Onlib?

- **Explore books:** Browse a collection of books by title, author, or category.
- **Search easily:** Find a book without scrolling through the entire collection.
- **Choose a membership:** Compare plans and select one that suits your reading habits.
- **Manage your account:** Try the demo registration and login features.
- **Save favourites:** Keep track of books you want to read.
- **Borrow books:** Try the borrowing feature available in the demo.
- **View your dashboard:** Check your reading activity and membership details.
- **Admin dashboard:** Explore the basic demo administration features.

## Membership plans

| Plan | Price | Monthly borrowing limit |
|---|---:|---:|
| Little Leaf | ₹99/month | 3 books |
| Open Book | ₹199/month | 10 books |
| Book Nook | ₹299/month | 20 books |

These are sample plans for the prototype. No real payments are processed.

## Built with

- HTML
- CSS
- JavaScript
- Browser local storage

The current version is a front-end prototype. It uses browser storage to demonstrate features without requiring a backend server.

## Getting started

You don't need to install anything to try the website.

1. Open this repository on GitHub.
2. Find `index.html`.
3. Download the file to your computer.
4. Open it in a web browser.

You can also publish the website using GitHub Pages.
